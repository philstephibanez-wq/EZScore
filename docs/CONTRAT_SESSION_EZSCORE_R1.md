# CONTRAT SESSION EZSCORE R1

Référence : issues #2 et #4.

- 1 Session = exactement 1 Groupe + exactement 1 Playlist.
- Le créateur est propriétaire et Chef d'orchestre.
- Création en brouillon privé.
- Aucun participant/invitation externe avant validation.
- Validation explicite : synchronise les membres actifs du Groupe et envoie les invitations.
- Date/heure informative uniquement : elle ne démarre, ne ferme et ne périme jamais une Session.
- Une Session peut ensuite être ouverte 0..N fois via des LiveRuns.
- Présentiel : écran commun ou partition vivante sur smart/tablette, sans audio réseau.
- Remote : miroir synchronisé + audio aller/retour, vidéo optionnelle.
