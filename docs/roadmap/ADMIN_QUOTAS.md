# Backlog — quotas d'analyse

À traiter après le nettoyage du dépôt, dans une livraison fonctionnelle séparée.

Prévoir dans l'administration :

- activation/désactivation du quota par case à cocher ;
- valeur numérique configurable ;
- distinction claire entre quota temporel et limite de file de jobs ;
- message d'erreur utilisateur explicite ;
- aucun fallback silencieux.

La désactivation provisoire d'une limite ne doit pas être mélangée au nettoyage structurel.
