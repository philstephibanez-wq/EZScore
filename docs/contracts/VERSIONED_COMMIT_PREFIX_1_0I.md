# Convention des commits versionnés — 1.0i

Préfixe obligatoire : `[vVERSION] type(périmètre): description`, avec `VERSION` correspondant exactement au fichier `VERSION` modifié dans le même commit. Exemple : `[v1.0i] fix(git): corriger le format du préfixe de commit`.

La forme littérale `[v]` est interdite. Les commits antérieurs 1.0f/1.0g/1.0h restent inchangés : ne pas réécrire l'historique partagé. Le contrat local contrôle AGENTS et la version effective de ce correctif.
