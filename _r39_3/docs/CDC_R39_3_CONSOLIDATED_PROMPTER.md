# CDC R39.3 — Prompteur consolidé

Le prompteur harmonique est un viewport fixe contenant une piste mobile.

La piste est pilotée par une transformation `translate3d()` calculée à partir de la timeline canonique.

Le suivi temps réel n'utilise pas le scroll horizontal natif.

Les composants de focus et de diagramme sont partagés et indépendants de ChordsLab afin d'être réutilisables dans Lyrics et Karaoke.
